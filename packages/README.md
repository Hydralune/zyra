# Packages

Shared runtime packages are split by responsibility. M0 defined the initial boundaries; M2 and M3 have filled runtime workers, commands, skills, symbolic reasoning, evaluation, and integrations enough to exercise the main graph.

Historical first-stage source pools are retired and provenance-only. Current capabilities execute from Zyra packages, apps, and formal runtime adapters; future work must preserve those owner and no-fallback boundaries.
