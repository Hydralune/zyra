## Decision

The normal `topology_policy` resolver activates `phase2_strongest_v1` as its
single default profile. The frozen Phase 1 deterministic baseline remains a
standby rollback target and is never silently selected.

This change is admitted only after the P2-S06-01 preflight and P2-S06-02 sealed
long-run evidence establish `activation_ready` / `deterministic_ready` status,
zero unsafe canonical commits, retained fail-closed receipts, successful
LoopX restart recovery, and real local, edge, and cloud dispatch causality.

## Preserved authority

The external mechanisms remain proposal-only. `GraphStateCustody` is the sole
canonical graph mutation owner; `MemoryFabric` remains the long-term fact
owner; `ResourceScheduler`, permissions, leases, budgets, event storage, and
artifact custody remain Zyra-owned. No policy training, fine-tuning, search, or
mutable learned parameters are introduced by activation.

## Rollback

Rollback resolves explicitly to `phase1_deterministic_baseline`. It preserves
the original receipts and emits the existing degradation/rollback evidence.
The baseline record remains immutable except for changing its runtime
activation state from active to standby.
