## Decision

Phase 2 maintains one strongest deterministic composition:

```text
LoopX
  -> MemoryContinuityVerifier
  -> ARG joint role-node-edge base topology
  -> CARD directional condition residual
  -> AgentPrune spatial/temporal pruning
  -> symbolic projector
  -> GraphDeltaBuilder
  -> GraphStateCustody commit
  -> MaAS operator/skill/worker/tool/model/breadth/depth candidates
  -> ResourceScheduler + permission + lease + physical dispatch
  -> verifier + causal receipts
```

The order is semantic:

- LoopX supplies a bounded continuation proposal from its private control
  state.
- Memory continuity must pass before a topology proposal can rely on restored
  facts or obligations.
- ARG is the sole primary topology proposal source and keeps role, node, and
  incident-edge selection in one hypothesis.
- CARD may add, drop, or reweight directional residual edges on the ARG base.
  It cannot replace the base generator.
- AgentPrune performs deterministic spatial and temporal communication
  pruning while protecting obligations, provenance, recovery, and critical
  paths.
- The symbolic layer may reject or repair a proposal. Only the custody path
  commits graph state.
- MaAS runs after topology commit and only selects concrete operator
  candidates. `ResourceScheduler`, permission, worker lease, and deployment
  runtimes make the physical decision and execute.

## Source-role limit

The `topology_proposal` domain has exactly one primary source,
ARG-Designer, and exactly two supplementary sources, CARD and AgentPrune.
MaAS is supplementary in `operator_selection`, where Zyra
`ResourceScheduler` is primary. LoopX is supplementary in long-horizon goal
control. Continuity, readiness, symbolic projection, and physical receipt
contracts are Zyra-owned.

The source registry records language custody, exact source commits, migration
modes, target paths, and proposal-only boundaries. Paper experiment runtimes,
providers, datasets, training code, unsafe code executors, and duplicate Agent
hosts are not migration targets.

## Determinism

The same immutable input snapshot and mechanism configuration digest must
produce identical proposal, projected delta, operator selection, and receipt.
Any optional pretrained signal must be a fixed, read-only observation with
model/version/input/output digest. It cannot independently commit or dispatch.
