# M3 Self-Check

M3 is accepted as complete after critical review and follow-up fixes.

Scope checked:

- Structured collaboration is on the main task graph path, not a side demo.
- `AgentMessage`, `PlanNode`, `ConstraintSet`, and `DecisionRecord` carry intent, summary, constraints, refs, expected output schema, state delta, route candidates, affected nodes, and decision checks.
- `ConstraintKeeper` emits `constraint_check` events during graph execution and control-event handling.
- `TopologyRouter` emits replayable `topology_route` events and selects M2 worker runtimes from task profile, runtime hints, worker capabilities, constraints, and failure history.
- `/change` creates affected-node metadata, supersedes stale nodes, creates a replan node, and records route/check evidence.
- `/inject` preserves node failure evidence, creates a recovery node, and records route/check evidence.

Issues found during self-check and fixed:

- Runtime browser plans in `state.metadata.runtime_hints.browser_plan` were not part of the router task profile, so a prepared browser execution plan could be underweighted. The router now includes runtime hints in route scoring.
- `DecisionRecord.checks` existed in the schema but route decisions did not consistently carry `ConstraintKeeper` results. Task-graph routes, requirement-change routes, and failure-recovery routes now attach check evidence.
- Applying a requirement change before a staged graph existed could create a replan node without any affected node. It now links the root node when no stage node is available.

Verification:

- `scripts/verify_m3.py`
- `tests.unit.test_symbolic_control`
- `tests.unit.test_task_graph`
- `tests.scenarios.test_m3_symbolic_collaboration`

Boundary:

- M3 does not claim full M4 long-horizon memory, full M5 edge-cloud scheduling, or M6 frontend upgrades. It leaves structured events and state transitions for those milestones.
- M4-M6 should be judged by whether they attach substantial internalized code and real runtime behavior to the M3 symbolic-control path, not by whether they add more placeholder fields around it.
