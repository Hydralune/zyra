# M1 Control Plane And Task Graph

M1 starts from a standard-library control plane because the local venv has no FastAPI or frontend dependencies yet.

Implemented runtime semantics:

- deterministic staged task graph: `plan -> route -> execute -> verify -> finalize`
- every graph node receives status transitions through `EventRecord`
- JSONL event log remains available for inspection
- SQLite stores normalized events, task rows, and full checkpoints
- API supports task creation, listing, checkpoint query, rerun, cancellation, and event query
- Web console shows task checkpoints and event stream records

Framework note:

- The current API is intentionally framework-light and can be replaced with FastAPI without changing the core graph/store contracts.
- The current Web console is static and can be replaced with React in a later frontend milestone.
