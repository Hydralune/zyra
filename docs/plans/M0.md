# M0 Engineering Baseline

M0 chooses a conservative local baseline:

- Python standard library first for the initial API, event log, and verification path.
- No external package dependency until the first real runtime module needs one.
- Shared dataclass schema in `packages/core/zyra_core` before orchestration logic.
- JSONL event log as the first persistence mechanism, because it is easy to replay and inspect.
- Static Web console shell before a frontend framework is introduced.

The baseline intentionally leaves room for later code-level reuse from the reference repositories, including `claude-code-best`, while keeping the first project commit easy to run locally.

This conservative baseline must not be reused as the execution style for M4-M6. Later milestones are expected to attach substantial memory, scheduler, fault-recovery, runtime, and UI modules to the contracts created here.
