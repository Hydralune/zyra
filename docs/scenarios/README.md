# Scenario Tests

Competition-aligned scenario tests will live here. M5 should add dynamic exception injection, requirement-change injection, and node-failure scenarios.

Scenario coverage should also prove that M4-M6 internalized modules are real runtime capabilities. M4 memory/compact/trajectory now has a first runnable subsystem; M5 scenarios must prove scheduler and recovery decisions change execution paths; M6 scenarios must prove the console uses real API/event/artifact data. A scenario that only exercises mocked memory, mocked scheduler decisions, or static UI data should not be treated as enough for first-stage completion.
