# 2026-09-06 CLI 交互与真实执行验收

## 范围与结论

检查 Windows 上的产品 TUI、斜杠命令、会话恢复、权限、文件执行、技能调用以及任务取消。使用用户已配置的 DeepSeek API，任务由真实 CLI 输入创建；API 查询和本地数据库只用于核对结果。

CLI 的任务、会话、权限和命令回执共用后端 API；标准模式的本地文件与 shell 操作通过登记的终端执行后端完成。主流程齐全，但本次实际发现了多处接口接线和终端生命周期问题，不能仅凭已有菜单和代码就认为功能已经验收。

未修改用户的模型配置，也未重启原有的 8000 API 和 18745 Web 服务。隔离验收使用 18846 API、18847 ConPTY 控制端口，状态和生成文件放在 `.tmp/cli-audit-20260906/`。

## 修复内容

| 范围 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| Windows 输入 | 任务完成、取消或关闭面板时切换 raw mode，可能导致后续输入失灵 | 产品会话持有终端输入模式；面板交接保持所有权，最终退出恢复终端 |
| 命令 | 无效恢复参数可能退出 CLI；运行时大小写和别名处理不一致 | 错误留在会话中；统一命令解析和可用状态检查，保留参数空格与换行 |
| 模型与模式 | 状态参数和选择行为混杂；恢复任务可能继承错误执行模式 | 明确查看状态与交互选择，恢复原任务的标准/封闭执行模式 |
| 会话与权限 | 重启或切换任务后丢失权限凭据，或复用其他会话凭据 | 按 API origin 和权限会话保存本地 custody；跨会话隔离，完成任务也可重新查看权限 |
| 命令回执 | `/skills`、`/mcp` 的解析参数被后端当成不支持的字段；错误信息丢失 | 忽略解析器内部 argv，保留 request/command 关联与明确错误 |
| 信息密度 | 上下文、记忆、验证界面堆叠原始结构和内部检查项 | 展示有界摘要、真实测试命令与结果；技术检查可用 `/verification details` 查看 |
| 会话列表 | 长提示词和原始时间戳铺满主对话 | 简短标题、本地时间、分页查看；恢复选择器同步收紧标题 |
| 交付物与导出 | 内部执行记录被列为交付物；空流式消息出现在原始对话和导出中 | 默认交付物列表过滤已知内部记录；显式产物 ID 仍可访问；跳过空消息 |
| 任务切换 | 旧计划、工具、代理和验证状态残留 | 保留会话消息，清空上一个任务的临时执行状态 |
| 文件编辑 | `file_edit` 先去管理工作区读取，而文件实际位于 CLI 当前目录 | 通过已授权的终端后端对实际工作区执行编辑 |
| shell 输出 | 子进程 exit 时提前结算，可能漏掉剩余输出 | 等待 close，保证输出管道已排空 |
| 内置技能 | 技能投影在错误工作区；调用参数仅在内部 metadata 中 | 投影到实际执行工作区；参数进入模型可见内容；报告技能声明可接受参数 |
| 技能返回 | 子技能成功但主任务拿不到正文 | 返回子运行的 final text，并计入输出估算 |
| 只读任务 | “不创建文件”“用户提供的事实”触发必须修改工作区的门禁 | 排除否定表达、已提供事实和英文词内误匹配；保留其他明确修改要求 |
| 取消任务 | 只改变任务状态，物理运行仍继续调用模型 | 物理运行监控同一 canonical task/run 的取消信号，终止进程与工具，返回 user_cancelled |
