## 当前结论

- Foundation 已演化出长期 session controller、有界增量产品状态、命令/overlay、Markdown、diff/tool/agent 浏览、权限范围、诊断和 PTY/性能 harness；组件、故障注入和 8 小时性能门已有证据，但 Phase G 长程运行、实机 IME 和最终发布候选尚未收口。
- 当前 P0 重点是 IME 实机与 Phase G 三次长程负载。CLI crash、异步重绘、clean-room 发布基础闭包、daemon restart/generation replacement、Web cross-view 对账和局部 failure impact 已关闭；控制 mutation lost-ack/race 的产品契约与确定性测试已关闭，真实长程控制仍归 Phase G 复验。
- typed API 已提供 session、task command、permission、diff、terminal、workspace、artifact 和版本化 event ingress。新增产品契约继续遵守 canonical owner，不从屏幕文本或 generic runtime summary 猜状态。
- Codex 专属账户、插件、Apps、Pets 已在 ADR-019 逐项完成产品边界决定，不用一句批量排除代替审计。
