The `.[` substring is incorrectly replaced with `[` in test report headlines.

Description

The root cause is in the module path computation used to build the test location: a `s.replace(".[", "[")` call on the module path string mangles any parameter value containing `.[`. The same defect also breaks vscode-python test discovery.

Expected behavior: the module path / location string must be returned unchanged, so parametrized ids such as `..[` are preserved exactly in report headlines. Fix the offending replacement and add a regression test covering a parametrized id containing `.[`.
